# 同类 AI 科研 Agent 项目借鉴点调研

> 2026-07 调研留档。已采纳的两项（novelty filtering、多轮自反思）已进 `tools/ideation.py`，
> 这里记录**未采纳**的借鉴点：每条给出处、机制、对 saagent 的适配判断，供后续迭代时翻阅。

## 调研对象

| 项目 | 出处 | 定位 |
|---|---|---|
| AI-Researcher (Stanford) | NoviScl/AI-Researcher | idea 生成质量的对照实验（LLM vs 人类研究者盲评） |
| AI-Scientist-v2 (SakanaAI) | SakanaAI/AI-Scientist-v2 | 全自动写论文（idea→实验→论文→自动评审） |
| AI-Researcher (HKUDS) | HKUDS/AI-Researcher | 全流程自动科研 + 基准评测 |
| opendraft | 开源写作 agent | source-grounded 的论文草稿生成 |

## 已采纳（仅索引）

- **逐篇重合度 novelty filtering**（Stanford）→ `critique_idea`：查重命中逐篇给 高/中/低 + 一句话依据，高重合亮警告。
- **num_reflections 式自反思**（SakanaAI）→ `propose_idea(reflections=2)`：每轮找最要害弱点就地修订，STOP 提前停。

## 未采纳借鉴点

### 1. BFTS 实验树（SakanaAI v2）

Best-First Tree Search 管理实验：每个实验节点是一次代码改动+运行，失败节点可回溯换分支，
由 experiment manager agent 调度。**不采纳的理由**：saagent 的实验阶段是"一个脚本+一个结果 JSON"
的最小可行设计，实验树的价值要在多轮长实验里才体现，现阶段引入只会把执行链路复杂化。
**将来触发条件**：当 run_experiment 出现明显的"失败后整段重来"浪费时再考虑，先从"失败节点缓存+
断点续跑"这种轻量形态做起，不必抄完整树搜索。

### 2. Docker 沙箱执行（HKUDS）

实验代码在容器内跑，依赖隔离、失败可丢弃。**不采纳的理由**：saagent 实验默认在本机 venv 执行，
且深度依赖 Qoder sub-agent（容器内没有认证态）；当前实验规模（脚本级）沙箱收益低。
**将来触发条件**：实验开始克隆外部仓库、装重依赖时（exec_assessment 的 level=中/重路线自动化时）。

### 3. Scientist-Bench 基准（HKUDS）

拿真实论文当 ground truth：给 agent 同样的起点材料，比生成的研究与真实论文的接近度。
**不采纳的理由**：这是评测基建，不是能力增强；saagent 当前靠人评（用户看报告）。
**将来触发条件**：想系统对比 prompt/流程改动的效果时，可先做微型版——固定 2-3 个已知领域，
对比新旧流程产出的 idea 与领域内真实后续论文的命中率。

### 4. idea 去重 cosine 0.8（Stanford）

生成大批 idea 后用 embedding 相似度 >0.8 判重合并，避免同质想法霸占评审预算。
**不采纳的理由**：saagent 单次只出 1-3 个 idea，量级不到需要向量去重的程度；
且现有 critique_idea 的检索查重已覆盖"与外部文献重合"这个更重要的维度。
**将来触发条件**：若加"批量发散模式"（一次生成 20+ idea 再筛），这条是第一个要补的。

### 5. Swiss-tournament ranking（Stanford）

idea 两两对决多轮排名，比单独打分更稳（LLM 打绝对分噪声大，两两比较一致性高）。
**不采纳的理由**：同上，idea 量级不够；对决式评审的 token 成本是 O(n·rounds)。
**将来触发条件**：批量发散模式落地后，与 cosine 去重配套引入。

### 6. source-grounded 写作（opendraft）

草稿每个论断必须锚定到具体来源片段，写作时先检索证据再落笔。
**不采纳的理由**：saagent 的报告写作已有类似约束（写作骨架要求引用卡片/原文，审稿人查证据链），
完整的逐句 grounding 会把写作速度拖慢数倍。
**将来触发条件**：若终审频繁出现"论断查无实据"类 P0/P1，再把 grounding 从"审稿人抽查"
升级为"写作时强制"。

## 复盘要点

- 这批项目的共同点：把"想法质量"的把关从单次 LLM 输出转移到**流程结构**上
  （反思循环/对决排名/树搜索/基准回归）。saagent 已吸收其中性价比最高的两条。
- 共同的坑：全自动化（SakanaAI 式一键出论文）在真实科研里评价两极，
  人在环（saagent 现状）仍是可信度更高的形态，不必追求端到端无人。
