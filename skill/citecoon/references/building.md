# 建图打法

目标是产出一张主干连通、覆盖"起源 → 主线 → 前沿"的引文图谱。顺序不固定，按图谱反馈自己决定下一步。

## 检索与种子

- `find_candidates` 召回候选：查询用 1-3 个关键词（长短语命中率低）；已知论文 id 时直接传（如 `arxiv:2401.12345`），双源验真，很新的论文也能命中。
- 候选列表由你判断指向哪个领域，有歧义就问用户，不要猜。
- `add_seed` 定 1-3 篇种子（锚定研究主题的论文），rationale 写清这篇论文的实际技术与主题的对应关系。

## 扩展引文网络

看 `graph_summary` 的断连节点与覆盖情况决定扩边方向（它给两个视图：引用数 Top 与最近入图年份序——盘点某个子方向的新节点看后者，引用序 Top 永远是 ResNet/ViT 类领域基石）：

- `expand_backward`：追一篇论文引用了谁（找起源）
- `expand_forward`：找谁引用了它（看发展）
- `expand_frontier` + `search_recent`：补最新论文
- `graph_search`：按主题补相关论文
- 图内定位用 `find_in_graph`：默认引用序只显前 10，找近年低引/零引新工作传 `newest_first=true`，否则它们会被截出视野

## 谱系接线（判断部分你来做）

很新的论文在引文数据库里往往没有参考文献记录，图上会断连。处理方式：`read_paper` 读它的 related work / references 章节，你从全文里挑出 5-12 个前驱工作的标题，一次性传给 `wire_predecessors`——它负责把标题解析成图谱节点并接边，解析失败的会列出来（可换更短的标题重试或放弃）。断连节点攒一批一起处理，不要一篇一篇地调。

## 联网查证

工具检索认不出的新名词、超新论文，用你原生的 WebSearch 查出论文的 arXiv id，再传给 `find_candidates` 验证入图。

## 检索注意事项

- 结果为空但提示"疑似限流"时：按提示等待后重试同一查询，不要立刻换词——空结果可能是假的。
- 提示"确实没有此文"时：换你的 WebSearch 查证，拿 id 直查。
- 有版本号的模型系列（某某 2.0 / 3 代）要主动查后继版本：新版本发布不久时引用关系还没进数据库，靠引文扩边永远发现不了。
- `find_candidates` 命中的候选可以直接 `read_paper` 读全文，不必先入图。

## 失败分支（每步都有去路，别卡死重试）

- 检索零命中：缩短 query（1-3 词命中率最高）或降级逐词 AND；同一查询两次零命中就换策略，不要第三次原样重试。
- arXiv PDF 拉取失败：请用户手动下载后用 `read_local_pdf`，或先读 abstract 落卡、全文欠账记入待办。
- `wire_predecessors` 部分标题解析失败：换更短标题重试一次；仍失败就放弃该条并在图谱断连处 take_note 记录，不要无限重接。
- 断连节点攒够一批（约 5 篇以上）再统一接线，不要一篇一篇调。
